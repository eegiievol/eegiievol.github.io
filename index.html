BeeCoach

A personal tool. Not a public product or service.

BeeCoach is a private, single-user tool that creates daily communication-coaching reports for its owner and saves them to the owner's own Google Drive.

Privacy policy

Who uses it: only the owner of this site. No other users can sign up or sign in.

Google data accessed: BeeCoach requests the drive.file scope only. It can create files and access only the files it created itself in the owner's Google Drive. It cannot see, read, or change any other files.

How data is used: files are created solely to store the owner's own daily reports. No Google user data is sold, shared with third parties, used for advertising, or used to train AI models.

Storage and security: access credentials are stored only on a private server controlled by the owner.

Revoking access: access can be removed at any time at myaccount.google.com/permissions.
